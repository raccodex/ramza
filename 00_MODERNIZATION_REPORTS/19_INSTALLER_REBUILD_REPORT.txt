2. Implemented Flow
-------------------
1. Welcome and explicit terms/authorization acceptance
2. Live server requirements
3. Empty database connection and environment validation
4. Site configuration and production license verification
5. Administrator account and password confirmation
6. Redacted review and explicit confirmation
7. Server-side install operation with accessible live pending state
8. Completion/security guidance or locked/recovery state

Normal successful submissions use POST/Redirect/GET. Steps are enforced by the
server-side session, not hidden fields. The production flow currently stops at
step 4 because no legitimate license contract exists in the package.
